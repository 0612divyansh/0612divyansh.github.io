# NeuroQuery Studio

> **Natural Language Database Explorer, Relational SQL Studio & Dynamic ERD Visualizer**  
> *Cycle #4 of the Antigravity Autonomous Launchpad by Divyansh Shandil (0612divyansh).*

Live Application: [0612divyansh.github.io/neuroquery-studio](https://0612divyansh.github.io/neuroquery-studio/)

---

## Capabilities

- **In-Memory Relational Engine**: Pure client-side relational SQL engine with joins, aggregations, filtering, ordering, and execution metrics.
- **Natural Language Synthesizer**: Translates conversational queries into ANSI/PostgreSQL SQL queries.
- **Interactive ERD Visualizer**: High-DPI Canvas 2D engine rendering entity relationships with draggable tables and bezier connector lines.
- **Dynamic Charting**: Client-side canvas charts (Bar, Multi-line, Area, Donut, Scatter) with live data binding and PNG export.
- **Query Plan Analyzer**: AST decomposition showing execution tree, estimated costs, and optimization advice.
- **Tactile Web Audio Synthesizer**: Interactive sound feedback for queries, navigation, and results.
