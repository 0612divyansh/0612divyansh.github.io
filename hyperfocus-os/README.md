## 🌿 Overview

**HyperFocus OS** (Cycle #3 of the Antigravity Autonomous 4-Day Launchpad) is a calm, distraction-free spatial productivity environment built for deep cognitive work. It combines real-time procedural audio synthesis with high-leverage task prioritization, live Markdown synthesis, and deep-work velocity tracking — running 100% client-side with zero external frameworks or audio assets.

---

## ✨ Highlights

- 🌿 **Procedural Biophilic Sound Synthesizer (Web Audio API)**:
  - 5 real-time synthesized channels: **Forest Rain** (pink noise + droplet resonances), **Alpine Wind** (LFO-modulated bandpass sweep), **Deep Brown Noise**, **Stereo Binaural Beats** (40Hz Gamma, 14Hz Beta, 10Hz Alpha, 6Hz Theta), and **Harmonic Biophilic Pad**.
  - 4 instant soundscape presets (`Forest Cabin`, `Deep Code 40Hz`, `Warm Brown`, `Night Pad`) + live HiDPI Canvas 2D spectrum visualizer.
- ⏱️ **Deep-Work Chronometer & Zen Chamber**:
  - Pomodoro (`25m`), Ultradian (`50m`), and Recovery (`5m` / `15m`) modes with SVG progress ring, completion chimes, and a full-screen **Biophilic Zen Chamber** breathwork pacer.
- 🎯 **Eisenhower Priority Matrix**:
  - Interactive 4-quadrant board (`Q1 Do First`, `Q2 Deep Work`, `Q3 Delegate`, `Q4 Parking Lot`) with HTML5 drag-and-drop, category tagging, active Focus Target locking (`◎`), and `localStorage` persistence.
- 📝 **Split Markdown Knowledge Pad**:
  - Dual-pane live Markdown editor + XSS-safe HTML preview (`Edit`, `Split`, `Preview` modes), multi-note tabs, word/reading-time counter, and 1-click `.md` export.
- 📊 **Deep-Work Velocity Analytics**:
  - Live KPI strip, 7-Day Deep-Work Minutes Canvas bar chart with `180m` goal line, Cognitive Domain Allocation donut chart, 1-click **1200×720 PNG Velocity Snapshot**, and JSON backup export.
- ⌘ **Command Palette & Keyboard Shortcuts**:
  - `Cmd/Ctrl + K` Command Palette, `Space` Start/Pause timer, `M` Mute/Unmute audio, `Z` Toggle Zen Mode.

## 🛠️ Quick Local Setup

```bash
git clone https://github.com/0612divyansh/hyperfocus-os.git
cd hyperfocus-os
open index.html
```

Or serve locally via Python:

```bash
python3 -m http.server 8080
```
